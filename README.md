# 大小姐的祭坛助手 — TLM JEI Bridge

一键从 JEI 把材料放上车万女仆祭坛并自动合成。One-click altar crafting for Touhou Little Maid via JEI.

作者：威严な大小姐（toi-et-moi）和 deepseek

## 版本支持

| Minecraft | 平台 | JEI | 分支 |
|---|---|---|---|
| 1.20.1 | Forge 47.4.0+ | 15.20+ | `master` |
| 1.21.1 | NeoForge 21.1+ | 19.9+ | `1.21.1` |

### 测试环境

- **1.20.1** — Touhou Little Maid 1.5.3、L2Backpack 2.6.0、Sophisticated Backpacks 3.26.12.2206
- **1.21.1** — Touhou Little Maid 1.5.3、L2Backpack 3.1.5、Sophisticated Backpacks 3.25.64.1919

其他相近版本通常也可以使用；如果遇到不兼容请反馈具体版本。

## 依赖

- Minecraft + Forge / NeoForge（对应版本）
- JEI（对应版本）
- Touhou Little Maid（运行时必需，编译时不需要）
- 多人游戏：客户端和服务端都需要安装本模组，且使用相同版本（联机协议版本需一致）

## 安装

1. 安装对应版本的 Forge / NeoForge。
2. 将 JEI 和 Touhou Little Maid 放入 `mods` 文件夹。
3. 将 `tlmjei-*.jar` 放入 `mods` 文件夹，启动游戏。

## 构建

### 1.20.1（`master` 分支）

需要 JDK 17，使用自带的 Gradle Wrapper：

```bash
./gradlew build
```

### 1.21.1（`1.21.1` 分支）

需要 JDK 21，使用自带的 Gradle Wrapper（Gradle 8.8）：

```bash
./gradlew build
```

## 功能

查看 JEI 中的车万女仆祭坛配方时，配方界面上会出现 JEI 自带的 **"+"** 按钮。
点击后会自动从可用来源取出材料、放到祭坛的 6 个基座上，并触发祭坛合成，产物生成在祭坛中心。

"+" 按钮在以下界面中都可以使用：

- 玩家背包、工作台、箱子 / 末影箱（原版菜单）
- L2Backpack 的背包、次元存储、快捷切换界面
- Sophisticated Backpacks 的背包界面

> 在支持的界面中，配方页面上会显示 "+" 按钮；实际传送需要附近有已搭建完成的祭坛，否则会提示"未检测到附近的祭坛"。

### 可合成配方优先

打开祭坛配方分类时，JEI 会把当前材料已经足够、可以立即一键合成的配方排在最前；材料不全的配方排在后面，并按已匹配的材料比例排序。

- 可用性由服务端提前批量校验，背包、附近容器、末影 / 次元存储、Curios 等来源都会计入，排序使用真实结果而不是客户端猜测。
- 使用 JEI 自带的 `CRAFTABLE` 排序阶段；JEI 客户端配置中的 `RecipeSorterStages` 默认包含它，如果手动删掉则不会排序。
- 刚打开界面、服务端结果尚未返回时，该配方会暂时按"不可合成"处理，不会错误地跳到最前。

### 材料处理

- 基座上已经有且符合当前配方的材料会被保留并复用，不会重复取材料。
- 材料不足时，JEI 的 "+" 按钮会像原版工作台一样变为不可用，并把缺少的配方槽位标红；补齐材料后按钮自动恢复。
- 可用性由服务端判断，背包、附近容器、末影 / 次元存储、Curios 等来源都会计入，客户端看不到的物品也不会被误判为缺少。若按钮状态尚未刷新时点击，服务端仍会拒绝合成。
- 基座上如果残留与当前配方无关的物品，需要先拿走，否则祭坛无法匹配配方（原版祭坛本身的要求）。

### 材料来源（按搜索顺序）

1. **玩家背包** — 主背包、快捷栏、盔甲栏、副手
2. **L2Backpack** — 普通背包、次元存储、末影背包、抽屉
3. **Sophisticated Backpacks** — 各级精妙背包
4. **Curios 饰品栏** — 放在饰品栏中的 L2 / 精妙背包
5. **周围容器** — 箱子、桶等（默认 32 格半径）

容器里的背包会被递归打开继续搜索，支持背包套背包。

### 庭灯补魔

祭坛合成需要 P 点时，优先消耗玩家自身的 P 点；不足的部分会从附近庭灯（shrine lamp）中按距离由近到远扣除。

如果范围内所有庭灯的储量加起来仍不足以补足差额，则不会扣除任何庭灯，保持原版"P 点不足"的行为。

### 配置

配置文件：`.minecraft/config/tlmjei-common.toml`

```toml
[altar]
    # 祭坛检测范围（格），默认 8，范围 1-64
    searchRange = 8.0

[containers]
    # 容器材料搜索范围（格），0 = 禁用，默认 32，范围 0-64
    searchRange = 32.0

[shrineLamp]
    # 庭灯补魔搜索范围（格），0 = 禁用，默认 8，范围 0-64
    searchRange = 8.0
```

多人游戏中配置以服务端为准。
